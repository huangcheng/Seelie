# Recall UI ("What do you remember?") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "What do you remember?" dialog that browses the pet's episodes (kind-tagged, relative timestamps, latest-100 default) and searches them — semantically via embeddings when the AI path is configured, by substring otherwise — plus a relationship header (days/bond/affection/count). Entries in both the pet context menu and the tray menu.

**Architecture:** `RecallDialog : PersonaDialog` (StatisticsDialog chrome) fed by `MemoryManager` getters; pure helpers in `src/RecallFilter.h` (substring filter + locale-aware relative time); one generic addition to `EmbeddingService` (`enqueueQuery(key, text)` → `queryEmbeddingReady(key, vec)`) reusing the worker pipeline. Spec: `docs/superpowers/specs/2026-07-18-recall-ui-design.md`.

**Tech Stack:** C++17, Qt6 Widgets, SQLite via MemoryManager, existing PersonaDialog/StyleUtils chrome. No new dependencies.

**Conventions (binding):** `QStringLiteral`; UPPERCASE acronyms; reason-comments; conventional commits; TDD; forward-declare + `QPointer` for MainWindow dialog members (mirrors `m_statsDialog`); all new UI strings `tr()` + hand-synced `Seelie_zh_CN.ts`.

```cpp
    connect(m_worker, &EmbeddingWorker::embedded, this, [this](qint64 id, const QVector<float> &vec) {
        if (m_pending > 0) --m_pending;
        if (id < 0) {
            // Query job: resolve the caller's storage key (digest for id -1).
            const QString key = m_queryKeys.take(id);
            if (!key.isEmpty()) {
                if (m_memory)
                    m_memory->setQueryEmbedding(key, vec);
                emit queryEmbeddingReady(key, vec);
                if (key == MemoryManager::kDigestQueryKey) {
                    emit digestEmbeddingReady(vec);  // back-compat
                }
            }
        } else {
            if (m_memory)
                m_memory->setEpisodeEmbedding(id, vec);
        }
    });
```

```cpp
    connect(m_worker, &EmbeddingWorker::failed, this, [this](qint64 id) {

        // Silent: row keeps NULL embedding / query key never lands.
```

```cpp
void EmbeddingService::enqueueQuery(const QString &key, const QString &text)
{
    if (key.isEmpty() || text.isEmpty()) return;
    m_queryKeys.insert(m_nextQueryId, key);
    enqueueEpisode(m_nextQueryId, text);
    --m_nextQueryId;
}
```

```cpp
#ifndef RECALLFILTER_H
#define RECALLFILTER_H

#include "MemoryManager.h"

#include <QDateTime>
#include <QString>

/**
 * Pure helpers for the Recall UI ("What do you remember?"). Header-only so
 * the unit tests link nothing beyond MemoryManager's header. No QObject, no
 * Qt global state — deterministic and trivially testable.
 */
namespace RecallFilter {

/// Case-insensitive substring filter over episodes. Empty query returns the
/// input unchanged (caller's default-view path).
inline QVector<Episode> contains(const QVector<Episode> &episodes, const QString &query)
{
    if (query.isEmpty()) return episodes;
    QVector<Episode> out;
    for (const Episode &e : episodes) {
        if (e.text.contains(query, Qt::CaseInsensitive)) out.append(e);
    }
    return out;
}

/// Relative timestamp for episode rows. `locale` follows ConfigManager's
/// Qt-locale code ("en", "zh_CN", ...) — zh strings when it starts with "zh".
/// Future/skewed timestamps clamp to the "just now" bucket; ≥7 days falls
/// back to the absolute ISO date (relative weeks read badly).
inline QString relativeTime(qint64 ts, qint64 nowMs, const QString &locale)
{
    const bool zh = locale.startsWith(QLatin1String("zh"), Qt::CaseInsensitive);
    qint64 diff = nowMs - ts;
    if (diff < 0) diff = 0;  // clock skew → just now
    const qint64 min = diff / 60000;
    if (min < 1)  return zh ? QStringLiteral("刚刚") : QStringLiteral("just now");
    if (min < 60) return zh ? QStringLiteral("%1 分钟前").arg(min)
                            : QStringLiteral("%1m ago").arg(min);
    const qint64 h = min / 60;
    if (h < 24)   return zh ? QStringLiteral("%1 小时前").arg(h)
                            : QStringLiteral("%1h ago").arg(h);
    const qint64 d = h / 24;
    if (d < 7)    return zh ? QStringLiteral("%1 天前").arg(d)
                            : QStringLiteral("%1d ago").arg(d);
    return QDateTime::fromMSecsSinceEpoch(ts).date().toString(Qt::ISODate);
}

} // namespace RecallFilter

#endif // RECALLFILTER_H
```

```cpp
QString RecallDialog::headerText() const
{
    if (!m_memory || !m_memory->isValid()) {
        return tr("Memory unavailable.");
    }
    const int count = m_memory->episodeCount();
    const int bond = m_memory->bondLevel();
    const int aff = m_memory->affection();
    const QString name = m_memory->effectiveName();
    if (name.isEmpty()) {
        return tr("Bond L%1 · Affection %2/100 · %3 memories")
            .arg(bond).arg(aff).arg(count);
    }
    return tr("Known %1 for %2 days · Bond L%3 · Affection %4/100 · %5 memories")
        .arg(name).arg(m_memory->daysMet()).arg(bond).arg(aff).arg(count);
}

void RecallDialog::renderDefault()
{
    if (!m_memory || !m_memory->isValid()) {
        renderEmpty(tr("No memories yet — chat with me more!"));
        return;
    }
    const auto episodes = m_memory->recentEpisodes(DEFAULT_LIMIT);
    if (episodes.isEmpty()) {
        renderEmpty(tr("No memories yet — chat with me more!"));
        return;
    }
    renderEpisodes(episodes);
}

void RecallDialog::renderEpisodes(const QVector<Episode> &episodes)
{
    m_list->clear();
    const qint64 nowMs = QDateTime::currentMSecsSinceEpoch();
    for (const Episode &e : episodes) {
        m_list->addItem(QStringLiteral("[%1] %2 — %3")
            .arg(e.kind, e.text,
                 RecallFilter::relativeTime(e.ts, nowMs, m_locale)));
    }
}

void RecallDialog::renderEmpty(const QString &text)
{
    m_list->clear();
    m_list->addItem(text);
}
```

```cpp
void RecallDialog::onSearchTextChanged(const QString &text)
{
    m_pendingQuery = text.trimmed();
    m_fallback->stop();
    m_debounce->start();   // restart-on-typing debounce
}

void RecallDialog::onDebounceTimeout()
{
    const QString query = m_pendingQuery;
    if (query.isEmpty()) {
        m_currentQueryKey.clear();
        renderDefault();
        return;
    }
    if (m_embed) {
        // Semantic path: embed the query, render on queryEmbeddingReady.
        // The fallback timer covers slow/failed embeds with substring results.
        ++m_querySeq;
        m_currentQueryKey = QStringLiteral("recall-%1").arg(m_querySeq);
        m_embed->enqueueQuery(m_currentQueryKey, query);
        m_fallback->start();
        return;
    }
    runSubstringSearch(query);
}

void RecallDialog::onFallbackTimeout()
{
    // Semantic path didn't answer in time — show substring results now; a
    // late queryEmbeddingReady still upgrades the list to semantic ranking.
    if (!m_pendingQuery.isEmpty()) {
        runSubstringSearch(m_pendingQuery);
    }
}

void RecallDialog::onQueryEmbeddingReady(const QString &key, const QVector<float> &vec)
{
    if (key != m_currentQueryKey) return;   // stale query — a newer one is pending
    m_fallback->stop();
    if (!m_memory || !m_memory->isValid() || vec.isEmpty()) return;
    const auto results = m_memory->recallByVector(vec, RESULT_LIMIT);
    if (results.isEmpty()) {
        renderEmpty(tr("Nothing like that yet."));
        return;
    }
    renderEpisodes(results);
}

void RecallDialog::runSubstringSearch(const QString &query)
{
    if (!m_memory || !m_memory->isValid()) return;
    const auto pool = m_memory->recentEpisodes(SUBSTRING_POOL);
    const auto hits = RecallFilter::contains(pool, query);
    const auto capped = hits.mid(0, RESULT_LIMIT);
    if (capped.isEmpty()) {
        renderEmpty(tr("Nothing like that yet."));
        return;
    }
    renderEpisodes(capped);
}
```

## Execution Errata (recorded 2026-07-18, after subagent-driven execution)

Issues found by the per-task review loops; all fixed in code. Per precedent.

1. **T1 — `take(-1)` consumed the permanently-reserved digest key (spec bug).**
   The plan's key-registry used `m_queryKeys.take(id)` for all negative ids;
   after the first `requestDigestEmbedding`, the reserved `-1 → kDigestQueryKey`
   mapping was gone, so every later digest embedding computed fine but was
   silently dropped. Fixed: `-1` is read via `value()` (permanent); only
   synthetic query ids (≤ -2) are one-shot (`take`). Regression test:
   `testDigestEmbeddingTwiceKeepsWorking` (`c06138b`).
2. **T4 — the plan's `testNoResultsState` was vacuous.** With one seeded
   episode, `list->count() == 1` was already true from the default view, so the
   QTRY passed before the debounce fired and `renderEmpty` was never exercised.
   Fixed by clearing the list synchronously on non-empty input (`3ce4c92`),
   then upgraded to a "Searching…" placeholder row (better UX, still
   deterministic) with content-based test predicates (`654ae42`).
3. **T4 — stale-result window on search clear.** `m_currentQueryKey` was only
   cleared when the debounce fired, leaving a ≤400ms window where a late
   `queryEmbeddingReady` could render stale results into an empty-search UI.
   Fixed: key cleared immediately in `onSearchTextChanged` (`654ae42`).
4. **T5 — "Close" has no cross-context translation (plan bug).** The plan said
   "reuse the existing Close entry" — but Qt resolves tr() per-class context,
   so RecallDialog saw the English source. Added "Close"→关闭 in the
   RecallDialog context (`c44880b`).
5. **Link requirements discovered in T3:** PersonaDialog AND EmbeddingService
   had to be added to `SEELIEPET_LIB_SOURCES` (signal address-of needs the
   staticMetaObject) — the plan's note covered PersonaDialog but missed
   EmbeddingService (`5569d12`).
